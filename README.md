# 衣序 · Everyday Wardrobe

手机优先的个人衣橱：衣橱列表/详情、近七日 OOTD、场景搭配画册。AI 在对话中维护仓库数据，网站按规则自动推荐，不调用模型或实时生成图片。

## 本地运行

需要 Node.js 20.19+（或 22.12+）。

```sh
npm ci
npm run dev
```

电脑打开终端输出的 Local 地址。手机与电脑在同一 Wi-Fi 时，可使用输出的 Network 地址。直接双击 HTML 不支持读取数据，请通过 HTTP 服务运行。

```sh
npm run validate
npm test
npm run build
npm run preview
```

## 内容与模块

- `public/data/wardrobe.json`：18 件插画示例单品、12 套正式搭配、天气规则。真实衣物未录入；所有图片均为项目自有 SVG 示例插画。
- `public/images/`：本地资源，可替换为实物 JPG/PNG/WebP；更新 JSON 中图片路径即可。
- `src/data.ts`：唯一衣橱读取入口；可替换为后续数据 API。
- `src/recommend.ts`：纯函数推荐器；先按场景、温度、风雨和可用性过滤，再稳定选取、减少七日重复。额外组合只使用互相兼容且符合天气条件的单品。
- `src/weather.ts`：Open-Meteo 城市搜索、七日真实预报、城市时区、一小时缓存、请求超时。失败时提示过期缓存，无可用天气时不生成推荐。
- `AGENTS.md`：与 AI 对话新增、修改、保存搭配的维护约定。

## 使用

第一次打开 OOTD 选择城市，之后记住城市与场景。切换日期即可查看该日推荐。默认场景为通勤，不推断用户的工作日/周末安排。推荐使用日间最高体感温度筛选，温差较大时补充外套建议；不是实时人体舒适度预测。

OOTD 第一块来自正式搭配，第二块为临时单品组合。新组合优先不同于当日主推荐，且不自动加入搭配库。列表和详情都可以跳转到关联单品。风雨条件没有合适方案时会明确提示，不降低条件拼出一套。

洗护和个人偏好没有单独页面；AI 可用 `available` 排除暂不可穿单品，用备注、兼容关系与搭配属性维护偏好。当前没有账号系统、服务端或购买建议。

## 静态部署

`npm run build` 生成 `dist/`，将整个目录部署到静态托管平台即可。路由使用 `#/ootd`、`#/closet`、`#/looks`，无需服务器重写。

当前发布采用 GitHub Pages，工作流位于 `.github/workflows/pages.yml`，推送到默认分支后自动检查与部署；地址为 `https://3246567702.github.io/wardrobe/`。工作流通过 `BASE_PATH=/wardrobe/` 构建，所有图片与 JSON 路径均支持子目录。

由于 Sites 接口连接失败，`.openai/hosting.json` 仅保留已注册、未发布的备用站点绑定。若以后改用 Sites，沿用该 ID，按源码同步、打包、版本保存和发布流程操作。不要把凭据写入仓库。

其他子路径部署时，设置 `BASE_PATH` 环境变量后构建；默认构建使用域名根目录。此版本的图片与 JSON 是公开静态资源，真实隐私数据应在接入访问保护或 API 后再放入。浏览器本地存储仅包含城市、场景与天气缓存。

天气来源：[Open-Meteo](https://open-meteo.com/)，城市搜索来源 GeoNames；外部字体不可用时回退到系统字体。页面无需任何 AI API 密钥。
